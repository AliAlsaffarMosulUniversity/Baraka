# بَركة | Baraka

الزايد عندك… بَركة لغيرك.

واجهة عربية متجاوبة للهاتف والحاسوب لمشاركة الفائض والتبرع به أو عرضه بسعر رمزي.

## التشغيل

افتح `index.html`، أو شغّل:

```sh
python3 -m http.server 8000
```

ثم افتح http://localhost:8000.

## الميزات

- البحث والتصفية حسب المدينة والقسم والسعر.
- إضافة العروض والصور مع ضغطها محلياً.
- معلومات تحضير الطعام وحفظه ومسببات الحساسية وموعد الاستلام.
- المفضلة والحجز التجريبي وإلغاؤه.

## حالة المشروع

نسخة أولية تجريبية تحفظ البيانات في localStorage على متصفح الجهاز فقط. العروض الأولية للتوضيح، والحجز لا يرسل طلباً حقيقياً. لا يوجد خادم أو حسابات أو محادثات مشتركة أو استقبال بلاغات بعد. الصور والخطوط الخارجية تحتاج اتصال إنترنت.

النسخة المنشورة: https://baraka-community-iraq.ali-alsaffar65.chatgpt.site

## الملفات

- `index.html`: هيكل الواجهة.
- `style.css`: التصميم المتجاوب.
- `app.js`: التفاعلات والتخزين المحلي.
