# بَركة | Baraka

الزايد عندك… بَركة لغيرك.

تطبيق عربي لمشاركة الفائض. يشمل محافظات العراق الـ19، رقم هاتف للتواصل المباشر، موقع استلام اختياري عبر إذن المتصفح وخريطة OpenStreetMap، صور العروض، البحث والمفضلة. لا توجد عروض تجريبية أو حجوزات.

## التشغيل والنشر

```sh
npm test
npm run build
```

ينتج `dist/server/index.js` بصيغة Cloudflare Worker ESM. الواجهة المصدرية في `public/`، والخادم في `worker/api.mjs`.

يلزم ربط R2 باسم `BUCKET` وتعيين متغير الخادم `ADMIN_EMAIL` ببريد المدير المتحقق منه. لا تضع بيانات اعتماد في المصدر. تسجيل المستخدمين عبر Firebase Authentication بحساب Google فقط. يتولى SDK إدارة الجلسة واستعادة كلمة المرور وتأكيد الإيميل. الخادم يتحقق من رمز الهوية لدى Google ومن مشروع Firebase ومعرف الحساب. لا توجد خدمة SMS ولا حاجة لتفعيل فوترة Firebase لهذه الإعدادات، مع مراعاة حصص الخطة المجانية. دخول Sites (ترويسات `oai-authenticated-user-*`) أُلغي؛ الخادم يتجاهل هذه الترويسات حتى لا يستطيع أحد انتحال حساب أو صلاحية المدير بإرسالها.

العروض تحفظ في R2 (`offers/`)، وصورها تحفظ منفصلة (`images/`) وتُخدم من `/api/images/<id>` حتى تبقى قائمة العروض خفيفة. ملكية العرض مرتبطة بمعرف Firebase للحساب الناشر. العروض القديمة المنشورة بحساب Sites يستطيع المدير حذفها، لكن ناشرها لا يستطيع إدارتها بعد الآن. لكل حساب حد أقصى 10 عروض في اليوم (المدير مستثنى). الخادم يسمح بالحذف للناشر أو المدير فقط. رقم الهاتف والموقع الاختياري يظهران للزوار. المفضلة محلية لكل جهاز.

العروض القديمة المحفوظة محلياً لا تنقل تلقائياً لغياب ملكية حساب موثقة؛ يستطيع أصحابها إعادة نشرها بعد تسجيل الدخول.

الرابط: https://baraka-community-iraq.ali-alsaffar65.chatgpt.site

اختبارات الخادم تغطي صلاحيات الحذف، منع تزوير الملكية، رفض الطلبات غير المصرح بها، والتحقق من بيانات العروض.

## إدارة الحساب

التسجيل والدخول من زر «دخول / تسجيل». يستطيع المدير استخدام إيميله المضبوط في `ADMIN_EMAIL`؛ يجب أن يكون بريد حساب Google متحققاً منه قبل منح صلاحيات المدير. إعداد Firebase للويب عام وليس مفتاح إدارة. لا تخزن كلمات المرور في قاعدة بيانات التطبيق.

يجب إضافة `baraka-community-iraq.ali-alsaffar65.chatgpt.site` إلى Firebase Authentication > Settings > Authorized domains. يرفض الخادم رموز جلسات Firebase التي لم تصدر عن مزود Google، حتى لو كان مزود آخر مفعلاً في المشروع.
